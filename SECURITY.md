# Security Policy

Galara is currently pre-development. Do not treat any prototype, testnet coin, or unofficial binary as having monetary value.

## Reporting

Until a dedicated security address is created, do not publish exploitable vulnerability details in a public issue. Contact the project owner privately through the official Galara Network account.

## Required controls

- Two-factor authentication on all administrative accounts
- Offline recovery-code backups
- No shared personal passwords
- Least-privilege contractor access
- Separate production and development credentials
- Signed releases and published checksums
- Documented key rotation and server recovery
- No single contractor controlling all infrastructure

## Mainnet rule

No mainnet release may occur without a documented vulnerability-reporting address and incident-response process.
